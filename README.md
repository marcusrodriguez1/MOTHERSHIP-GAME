# MOTHERSHIP-GAME

Paste the the code of Main.java into VS Code and name the file the same name.

Then, in the terminal of VS Code, Paste this:

cd ~/Desktop/SpaceGame
mvn clean compile exec:java

Then, the game should open after some seconds, maybe a bit longer.
Bear with me this is a work in process.
